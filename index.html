Studio Quick-Start Guide

  1. Select Educational Level: Choose Primary, Secondary, High School, or University to apply appropriate color coding and age-calibrated phrasing.
  2. Define Task in Generator: Enter your learning objective, skills, and task modality. The recommendation engine matches the evidence type to the optimal instrument.
  3. Refine Criteria & Math: Use the Rubric Builder or Observation Tools to adjust descriptors and verify that points/weights equal your exact target maximum.
  4. Audit with Quality Control: Review the 12-point QC report in the Assessment Editor to resolve any alignment or mathematical warnings.
  5. Export & Print: Generate PDF, DOCX, PPTX, XLSX, or A4 printouts with grayscale legibility.

Core ELT Assessment Principles

  • Construct Validity: Assess only criteria explicitly tied to your learning objectives. Never add filler criteria.
  • Observable Descriptors: Replace subjective adjectives ("good fluency") with observable language evidence ("maintains speech with occasional pauses for lexical planning").
  • No Double Penalization: Separate grammatical accuracy, lexical range, and task achievement so a single error is not deducted across multiple rows.
  • CEFR Reference Scope: CEFR A1–C2 scales guide task complexity and expected linguistic repertoire; classroom tasks do not formally certify proficiency.
